# 顔文字アシスタント - Chrome拡張機能

任意のウェブページで右クリックして、可愛い顔文字を挿入できます！

## 機能

✨ **2つの起動方法** - Shift+右クリックで直接開く / 右クリックメニューから「顔文字アシスタント」を選択
📂 **カテゴリ管理** - 5つの組み込みカテゴリ（喜・怒・哀・楽・その他）+ お気に入り + 最近使用
⭐ **お気に入り** - よく使う顔文字をマークして素早くアクセス
🕐 **最近使用** - 最近使った10個の顔文字を自動記録
🎨 **カスタマイズ** - カテゴリと顔文字の追加・編集・削除が可能
🔁 **連続挿入** - 顔文字をクリックしてもメニューが開いたまま、連続して挿入可能
📍 **位置記憶** - 前回のメニュー位置を記憶し、次回も同じ場所に表示
🎯 **ドラッグ可能** - メニューを好きな位置に自由にドラッグ
🌏 **多言語対応** - 言語を自動検出（繁体字中国語/英語）
💾 **データ同期** - Chrome Storageに設定を保存

## インストール方法

### 1. プロジェクトをビルド（未ビルドの場合）

```bash
npm install
npm run build
```

### 2. Chromeに読み込む

1. Chromeブラウザを開く
2. `chrome://extensions/` にアクセス
3. 右上の「デベロッパーモード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. プロジェクトの `dist` フォルダを選択
6. 完了！拡張機能のインストールが成功しました 🎉

## 使い方

### 基本的な使い方

**方法1：Shift + 右クリック（クイックオープン）**
1. 任意のウェブページの**入力フィールド**または**テキストエリア**で `Shift + 右クリック`
2. メニューが前回の位置に表示されます（初回は入力フィールドの近くに表示）
3. 顔文字をクリックするとカーソル位置に挿入されます
4. メニューは開いたままなので、続けて選択できます
5. 右上の ✕ ボタンをクリックして閉じます

**方法2：コンテキストメニュー**
1. 任意のウェブページの**入力フィールド**または**テキストエリア**で右クリック
2. ブラウザのコンテキストメニューから「顔文字アシスタント」を選択
3. メニューが前回記憶した位置に表示されます

**メニューのドラッグ**
- メニュー上部のグレーのタイトルバーをドラッグ
- 位置は次回の起動時に保存されます

### 顔文字の管理

1. 右クリックしてメニューを開く
2. 右上の「⚙️ 設定」タブをクリック
3. 以下の操作が可能：
   - カスタムカテゴリの追加
   - カテゴリ名の変更（システムデフォルトを除く）
   - カテゴリの削除
4. 各カテゴリ内で：
   - 顔文字の追加（下部の入力フィールド）
   - お気に入りに登録（⭐ アイコン）
   - 順序の調整（↑↓ 矢印）
   - 項目の削除（🗑️ アイコン）

## よくある質問

### Q: 顔文字アシスタントが表示されない？
A: 以下を確認してください：
- 拡張機能が正しくインストールされ、有効になっている
- **編集可能なエリア**（input、textarea、contentEditable）でクリックしている
- `Shift + 右クリック` で直接開くか、コンテキストメニューから「顔文字アシスタント」を選択

### Q: メニューの位置がおかしい、または見えない？
A: 以下の方法で解決できます：
- 初回使用時は入力フィールドの近くに自動配置されます
- タイトルバーをドラッグして好きな位置に移動
- 位置は次回起動時に保存されます
- 位置をリセットするには、`chrome://extensions/` から削除して再インストール

### Q: メニューを閉じるには？
A:
- 右上の ✕ ボタンをクリック
- またはメニュー外の任意の場所をクリック

### Q: 拡張機能を更新するには？
A:
1. コード変更後、`npm run build` を実行
2. `chrome://extensions/` にアクセス
3. 拡張機能カードの更新アイコン 🔄 をクリック

### Q: データは保持されますか？
A: はい！すべてのカスタムカテゴリ、顔文字、メニュー位置はChrome Storageに保存され、拡張機能をリロードしても失われません。

### Q: 顔文字をクリックしてもメニューが閉じないのはなぜ？
A: これは機能です！メニューを再度開くことなく、複数の顔文字を連続して挿入できます。完了したら、右上の ✕ ボタンをクリックして閉じてください。
